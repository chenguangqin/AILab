## 检验科运行模拟数据

来源：客户提供的模拟CSV。共1,426条记录，覆盖2026-08-03至08-08。

主要字段：

- 标本：标本ID、来源科室、患者类型、标本类型、专业组；
- 时间：采集、签收、前处理开始/完成、上机、报告；
- 指标：前处理耗时、TAT、目标TAT、是否超时；
- 调查维度：采集时段、工位、仪器、操作人、错误类型。

课程可验证的植入模式：

- 早高峰平均前处理耗时明显增加；
- 儿科门诊早高峰报错率明显高于其他来源；
- 样本量不足、条码识别失败等错误集中；
- 报错记录的前处理耗时高于正常记录。

限制：

1. 只有6天，不能建立月度或季节性基线；
2. 仪器编号与专业组疑似独立随机分配，不用于仪器根因结论；
3. 微生物和急诊超时率受目标TAT口径强烈影响；
4. 缺少排班、质控、报警、重采和维护记录；
5. 只能形成候选原因，不能证明现实因果关系。

## 智能审核模拟数据

使用虚构分析物和教学阈值，只验证：

- 规则优先；
- 近期历史优先；
- 按需读取更久历史；
- 质控/报警冲突；
- 缺失数据转人工。

不验证临床规则本身的医学正确性。
