# E5：Agent评估与生产化闸门

## 我们提供

- 四个教学审核案例；
- 版本化规则、近期/长期历史、质控和仪器报警；
- 按需取数LangGraph；
- 预期工具轨迹；
- 缺失数据和证据冲突案例。

## 学员任务

1. 验证低风险案例不会读取不必要的历史和设备数据。
2. 验证近期历史不足时才读取更久历史。
3. 验证规则命中、质控失败或数据缺失时进入人工复核。
4. 为每个案例断言结果和允许的工具轨迹。
5. 比较“全量上下文”与按需取数的输入规模和步骤数。
6. 将回归分数写入Langfuse。

```bash
roche-lab review evaluate
```

本实验验证工程行为，不验证任何临床规则的医学正确性。
