# 报告审核与复检

## 一、审核层级
- **自动审核（Auto-verification）**：满足全部放行条件的结果由系统自动发出；
- **人工审核**：不满足自动审核条件的结果转检验人员人工判断。

## 二、自动审核放行条件（需同时满足）
1. 当批室内质控在控；
2. 仪器无报警（无吸样异常、无凝块报警等）；
3. 结果在项目参考区间或历史一致性范围内；
4. 未触发危急值；
5. 未触发下述复检规则。

## 三、复检（复查）规则（示例）

| 触发条件 | 复检动作 | 说明 |
|---------|---------|------|
| 结果达危急值 | 复测 + 人工确认 | 禁止自动放行 |
| Delta check 超限 | 与历史结果比对、必要时复测 | 防止标本张冠李戴 |
| 结果超线性上限 | 稀释复测 | 超测量范围 |
| 血常规散点图异常/仪器报警 | 推片镜检 | 如原始细胞、血小板聚集 |
| 首次异常且无历史 | 复测确认 | 缺少历史参照 |

## 三点五、Delta check 说明
Delta check 比较同一患者本次与上一次结果的差异，超过设定阈值则提示可能标本错误、明显病情变化或分析误差，需人工介入判断而非直接放行。

## 四、常见问答

### Q1：什么样的结果可以走自动审核？
质控在控、仪器无报警、结果在参考区间或与历史一致、未触发危急值与复检规则的结果，可自动放行。任一条件不满足即转人工。

### Q2：CREA 出现少见的高值，专家会怎么审核？
危急值 CREA 较少见、误测概率相对高。专家思路通常是：先看当批质控是否在控、当时仪器有无报警，再看该患者前后标本与历史趋势、是否 Delta check 超限，排除标本混淆与干扰后再判断，必要时结合临床诊断与其他检查。

### Q3：TAT（周转时间）如何要求？
急诊项目一般要求自标本接收起 30–60 分钟内出报告，常规生化半天内，具体以本院 TAT 目标为准。超时需分析原因（如上午标本堆积在前处理环节）。

### Q4：自动审核规则由谁制定和维护？
由科室专业组结合厂商建议、本院历史数据与专家经验制定，经审批后配置到 LIS/中间体系统，并定期评估其误放行与误拦截情况。规则变更需版本化留痕。
