# MacBook Pro（M3 系列）

- **品牌**：Apple
- **颜色**：深空黑 / 银色 / 深空灰

## 主要卖点

1. 14.2 / 16.2 英寸 Liquid Retina XDR mini-LED 屏幕，1600 尼特峰值亮度，色彩还原专业。
2. 搭载 M3 / M3 Pro / M3 Max 芯片，统一内存最高 96GB，专业创作不卡顿。
3. 全系最长 22 小时续航，配合 MagSafe 3 + Thunderbolt 4 接口，外出工作无忧。

## 退换货要点

- 未激活原封 14 天内可退；
- 拆封后退货收 15% 折损费；
- 定制配置（CTO 机型）原则上不接受无理由退货。

## 适用人群

视频剪辑师、软件工程师、UI / UX 设计师、对色彩还原和续航有要求的内容创作者。
