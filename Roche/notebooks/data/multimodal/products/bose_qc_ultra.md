# Bose QuietComfort Ultra 头戴式耳机

- **品牌**：Bose
- **颜色**：黑色 / 雾白 / 月光蓝

## 主要卖点

1. CustomTune 技术为每只耳朵定制声学曲线，沉浸式音频效果配合空间音频体验拉满。
2. 主动降噪表现是 Bose 历代最强，配合 Aware Mode 可以一键切换通透。
3. 蓝牙 5.3 多点连接，最多同时连两台设备，听歌 + 通话切换无感。
