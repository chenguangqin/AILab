# Anker PowerCore 系列移动电源

- **品牌**：Anker（安克）
- **型号**：PowerCore 24000 PD 140W（适用于 MacBook Pro 系列）
- **首发价**：~899 元起

## 主要参数

- 容量：24000mAh / 86.4Wh（接近民航随身携带上限 100Wh）
- 输出：双 USB-C + 单 USB-A，最大单口 PD 3.1 140W
- 输入：USB-C PD 100W 快充输入（约 58 分钟充至 80%）
- 协议：USB PD 3.1 / PPS / QC4+ / SCP，兼容主流快充手机笔记本
- 显示：高清数字电量显示屏，可显示输入输出功率、剩余时间
- 安全：ActiveShield 2.0 主动温控，过充过放保护
- 重量：约 630 克，机身铝合金框架
- 包装：充电宝主机、USB-C to USB-C 100W 编织线、收纳袋、说明书

## 适用场景

- 商务差旅：一块顶 MacBook Pro 14" M3 满电 1.5 次，覆盖一整天会议
- 多设备同充：iPhone 15 Pro Max + iPad + AirPods Pro 2 可同时快充
- 摄影后期党：给 14"/16" MacBook Pro 续命，后期直出不焦虑
- 户外创作：搭配 DJI Mini 4 Pro 充电管家，可在野外为电池续命

## 推荐语

PowerCore 24000 是 Anker 把"笔电级别快充"塞进随身充电宝的一款代表作。140W PD 3.1 输出对 16" MacBook Pro M3 也能给到接近原装满速的功率。86.4Wh 容量略低于民航 100Wh 上限，可以随身上飞机但需要在机场报备。重量 630g 算一块"砖"，背包党比较友好；轻装出门可以看下 PowerCore 10000 系列。建议配合 Anker 100W 编织线一起用，普通 60W 线会成为瓶颈。
