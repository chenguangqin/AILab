# 三星 Galaxy S24 Ultra

- **品牌**：Samsung（三星）
- **型号**：Galaxy S24 Ultra（SM-S928U/N）
- **首发价**：~9999 元起（12GB+256GB）

## 主要参数

- 屏幕：6.8 英寸 Dynamic AMOLED 2X，3120×1440 分辨率，自适应 120Hz，峰值亮度 2600 尼特
- 处理器：高通骁龙 8 Gen 3（For Galaxy 定制版）+ Adreno 750
- 内存 / 存储：12GB RAM + 256GB / 512GB / 1TB UFS 4.0
- 后置：200MP 主摄（OIS）+ 50MP 5x 长焦 + 10MP 3x 长焦 + 12MP 超广角，最高 100x 数字变焦
- 前置：12MP，f/2.2
- 机身：钛金属中框 + Gorilla Armor 玻璃，IP68 防尘防水
- 内置 S Pen，支持手写、笔记、远程快门
- 系统：One UI 6.1（Android 14），承诺 7 年 OS 更新
- 颜色：钛灰 / 钛黑 / 钛紫 / 钛黄

## 适用场景

- 拍月亮、拍演唱会：100x 变焦在长焦场景下没有对手
- 商务会议记录：S Pen 手写 + Galaxy AI 录音转写支持中英日韩多语言
- 大屏党：6.8 英寸的视觉体验配合 120Hz 滑动追剧、看股票图舒服
- 安卓生态用户：与 Galaxy Buds3 Pro、Galaxy Watch 6、Galaxy Tab S9 联动顺畅

## 推荐语

S24 Ultra 是三星首次把钛金属带到旗舰机身，重量控制和质感都比 S23 Ultra 上一个台阶。Galaxy AI 的圈选搜图、即时翻译实测在跨境购物、出差场景非常实用。骁龙 8 Gen 3 性能强悍但发热相比定制版略明显，长时间高负载游戏建议配磁吸散热。如果是从 S22 Ultra 或更早升级，体感差距明显；S23 Ultra 用户可以再等一代。
