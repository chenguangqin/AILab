# MacBook Pro 14 / 16 英寸（M3 系列）

- **品牌**：Apple
- **型号**：MacBook Pro 14"（M3 / M3 Pro / M3 Max）
- **首发价**：~14999 元起（M3 标准版 14 英寸）

## 主要参数

- 处理器：Apple Silicon M3 / M3 Pro / M3 Max（3nm 工艺，统一内存架构）
- 显示屏：14.2 / 16.2 英寸 Liquid Retina XDR mini-LED，ProMotion 120Hz，1600 尼特峰值亮度（HDR）
- 内存：8GB / 16GB / 36GB / 48GB / 96GB 统一内存
- 存储：512GB - 8TB SSD
- 接口：3 × Thunderbolt 4（M3 Pro 及以上为 TB4）+ HDMI + SD 卡槽 + MagSafe 3 + 3.5mm 耳机口
- 续航：最长 22 小时视频播放（M3 14")
- 摄像头：1080p 高清 FaceTime HD 摄像头
- 颜色：深空黑、银色、深空灰

## 适用场景

- 视频剪辑：Final Cut Pro 4K ProRes 多机位无压力，导出速度比 Intel 时代提升一个量级
- 软件开发：Docker、Xcode、Android Studio 同时跑，统一内存让大型项目编译飞快
- 设计创作：mini-LED 屏幕色域覆盖广，配合 Affinity、Figma 调色还原准
- 日常办公 + 出差：续航够长，从早会带到下午茶不用插电

## 推荐语

M3 系列最大的进步是 GPU 端的硬件级光线追踪和动态缓存，专业创作者能直接吃到性能红利。如果你的工作流是剪片、写代码或者跑 ML 推理，闭眼上 M3 Pro 起步；如果只是文档、网页、轻度修图，M3 标准版完全够用。注意一下黑色款指纹比较明显，建议搭配 Apple 官方原装保护壳或 Bose、Anker 出的同色配件。
