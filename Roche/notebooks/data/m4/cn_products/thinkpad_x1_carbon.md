# 联想 ThinkPad X1 Carbon Gen 12

- **品牌**：Lenovo（联想）
- **型号**：ThinkPad X1 Carbon Gen 12（2024 款）
- **首发价**：~14999 元起

## 主要参数

- 处理器：Intel Core Ultra 7 155H（Meteor Lake 架构，集成 NPU）
- 显卡：Intel Arc Graphics 集成显卡
- 内存：16GB / 32GB / 64GB LPDDR5X-6400（板载，不可升级）
- 存储：512GB / 1TB / 2TB PCIe 4.0 NVMe SSD
- 屏幕：14 英寸 2.8K OLED 触控屏 / WUXGA IPS 多版本可选，HDR True Black 500
- 接口：2 × Thunderbolt 4 + 2 × USB-A 3.2 + HDMI 2.1 + 3.5mm 耳麦口
- 摄像头：1080p 红外摄像头，支持 Windows Hello 人脸登录
- 重量：约 1.09 公斤（碳纤维顶盖）
- 续航：57Wh 电池，最长约 16 小时
- 键盘：经典 ThinkPad 小红点 + TrackPad，1.5mm 键程
- 系统：Windows 11 Pro，可选 Linux 兼容版

## 适用场景

- 程序员主力机：编译性能 + Linux 兼容性 + 全尺寸键盘
- 商务出差：全机重量 1.09kg，续航 16 小时，安检免开机包
- 数据分析师：32GB 内存 + Intel NPU 跑本地 AI 推理顺畅
- 高频会议党：双阵列麦克风 + AI 降噪，远程会议清晰度业内领先

## 推荐语

X1 Carbon Gen 12 最大的卖点是 Intel Core Ultra 平台带来的 AI PC 体验，集成 NPU 跑本地 LLM、Stable Diffusion 比上代纯 CPU 快出明显档次。OLED 触控版的色彩对设计师非常友好，办公党选 IPS 版续航更长。键盘手感依然是 ThinkPad 系列最稳的代表，回报力清脆。短板：板载内存不可升级，建议一次到位上 32GB。整体而言这台是商务本里"工程师友好度"最高的选择之一。
