Use this **curated set** as-is. Each URL was confirmed to resolve (`HTTP 200`) **and** to actually
depict its subject, so you don't have to guess a stock-photo slug. Wire each into its matching section
using the description as the alt text; **do not substitute your own recalled slugs.**

Hotlink them with sizing params for performance (append `?auto=format&fit=crop&w=1600&q=80` for the
hero, `&w=800` for thumbnails) and mark hotlinked URLs `PROTOTYPE ONLY` in code.

**If a URL ever fails to load** (Unsplash can retire a photo), fall back to a neutral placeholder
(`https://picsum.photos/1600/900`) rather than shipping a broken image slot or a confidently-wrong
guess. A placeholder is honest; a wrong photo is a defect.

> Why curated? A stock-photo slug is opaque, and a reachable URL says nothing about *what* it shows, so
> free-choosing images is a common source of broken or off-subject thumbnails. Pinning a verified set
> with descriptions removes that failure mode entirely. When you author your *own* intake, do the same:
> confirm each image's subject before wiring it in, exactly the bar you'd hold any other load-bearing
> fact to.
